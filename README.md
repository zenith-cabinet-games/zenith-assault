# ZENITH ASSAULT

A free early-80s style arcade shooter. One HTML file, no tracking, no network requests.

- 50 stages, 10 bosses, bonus waves, power capsules, arcade high score table
- Arrows or A/D move, Space or Z fire, P pause, M mute, C scanlines, F fullscreen
- Gamepad supported. High scores are saved in your own browser only.
